# Reporting a security issue

Email [hello@forgeweb.app](mailto:hello@forgeweb.app) with the subject
“Forge Web security”. Include affected revision or URL, reproduction steps,
and the impact you observed. Please keep vulnerabilities, credentials, and
player data out of public issues and pull requests.

This reaches the Forge Web maintainer. For issues confined to upstream
Card-Forge, use [its security policy](https://github.com/Card-Forge/forge/security).

The maintained release is the current version at [forgeweb.app](https://forgeweb.app).
There is no guaranteed response time or support for older releases and forks.
